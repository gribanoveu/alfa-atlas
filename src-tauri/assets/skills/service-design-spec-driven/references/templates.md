# Шаблоны результата

## Упрощённый формат для небольших задач

Если задача маленькая, не нужно писать большой документ. Достаточно:

```markdown
## Сервис или модуль

Короткое название.

## Проблема

Что болит.

## Результат

Что станет возможно.

## Сценарии

1. Пользователь может ...
2. Система проверяет ...
3. Клиент получает ...

## Контракт

- Операция:
- Вход:
- Успех:
- Ошибки:
- Идемпотентность:
- Права доступа:

## Данные

- Сущности:
- Источник правды:
- Особенности хранения:

## Риски

- Риск 1:
- Риск 2:

## План

1. Минимальный срез:
2. Расширение:
```
