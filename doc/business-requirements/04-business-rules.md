# 4. Бизнес-правила и ограничения

Целевые правила продукта. Что из этого уже есть в приложении — см. [../implemented-features.md](../implemented-features.md).

## 4.1. Правила продукта

| ID | Правило | Смысл для бизнеса |
|----|---------|-------------------|
| R-01 | Вставка шаблонов AsciiDoc разрешена **только** в активный `.adoc` файл | JSON — источник схем/примеров, не цель шаблонной вставки |
| R-02 | AI-правки применяются только после явного подтверждения пользователя | Человек остаётся владельцем текста документации |
| R-03 | Отклонение подсказки (Esc / «Отклонить») не изменяет файл | Безопасный отказ от предложения AI |
| R-04 | Commit запрещён без сообщения коммита | Минимальная дисциплина истории изменений |
| R-05 | Commit запрещён без staged-файлов | Нельзя создать пустой коммит из UI |
| R-06 | Нельзя закрыть последнюю вкладку редактора | Всегда есть активный рабочий файл |
| R-07 | Контекст AI привязан к текущему методу (`@folder`, `@request.json`, `@response.json`) | Снижение «галлюцинаций» вне открытой папки |
| R-08 | Отправка сообщения в чат требует непустого текста | Защита от пустых запросов |
| R-09 | В текущем объёме нет модели прав (viewer / editor / admin) | Любой пользователь сессии — полноценный редактор *(прототип)* |

## 4.2. Эвристики качества документации *(продуктовая логика AI)*

| Эвристика | Пример из демо |
|-----------|----------------|
| **Полнота** | Поля `errorCode` / `errorMessage` есть в `response.json`, но отсутствуют в `description.adoc` → предложить раздел «Коды ошибок» |
| **Согласованность** | `amount` описан как сумма в копейках, а в примере/формулировке воспринимается как рубли → уточнить формулировку |
| **Оформление** | Trailing whitespace, несогласованное выравнивание таблиц → панель «Форматирование» |

---

## 4.3. Нефункциональные ожидания

| Категория | Ожидание |
|-----------|----------|
| **Язык** | Основной UI — русский; Git-термины могут быть на EN (`Staged`, `Changes`, `Commit message`) |
| **Формат доков** | AsciiDoc — основной формат описания API. Редактор открывает **только**: `.adoc` / `.asciidoc`, `.json`, `.md` / `.markdown`, `.txt`, `.puml` / `.plantuml`, `.yaml` / `.yml`, `.mmd` / `.mermaid`. Прочие форматы не открываются. |
| **UX-парадигма** | Desktop IDE (панели, вкладки, status bar), не веб-портал |
| **Доверие к AI** | Индикатор «AI-индекс актуален»; preview / подтверждение перед применением |
| **Скорость типовых операций** | Шаблоны + quick actions вместо ручного набора разметки |
