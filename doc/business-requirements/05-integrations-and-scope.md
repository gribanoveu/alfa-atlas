# 5. Интеграции, метрики и границы scope

Актуальное as-built состояние приложения: [../implemented-features.md](../implemented-features.md).

## 5.1. Интеграции

| Система | Целевой смысл | Статус в docflow (сейчас) |
|---------|---------------|---------------------------|
| **Git (локальный)** | Учёт изменений docs: stage / unstage / commit / history | Нет (clone — UI-заглушка) |
| **AI-провайдер** | Генерация, сверка, уточнение формулировок, перевод | Нет (пустая панель «Ассистент») |
| **GitHub / GitLab / Bitbucket** | Remote, push/pull, PR | Нет |
| **Auth / IdP** | Доступ команды, SSO | Нет |
| **Файловая система / проект** | Открытие папки, настройки окна и layout | Частично: open folder + `~/.docflow` + `{project}/.docflow/layout.json` |

---

## 5.2. Критерии успеха (бизнес-метрики)

| Метрика | Интерпретация |
|---------|---------------|
| Доля методов с полным комплектом (`adoc` + `request` + `response`) | Полнота структуры |
| Число недокументированных полей после AI-прохода | Качество синхронизации docs ↔ схемы |
| Время от открытия метода до commit | Эффективность workflow |
| «Покрытие документацией» (BR-9) | Прогресс команды |
| Доля принятых vs отклонённых AI-подсказок | Полезность ассистента |

---

## 5.3. Out of scope / ещё не сделано в docflow

| Область | Комментарий |
|---------|-------------|
| Аутентификация, роли | Нет модели доступа |
| Push / pull, remote, PR, code review | Нет |
| Реальный AI, Git backend, clone | Панели-заглушки; clone — только UI |
| Дерево файлов и open/save с диска | Нет (есть только open folder + Monaco Untitled) |
| Рабочие пункты верхнего меню | UI-chrome без действий |
| Preview / split AsciiDoc | Нет |
| Недавние проекты | Placeholder на Welcome |
| KPI «Покрытие документацией» | Нет |

---

## 5.4. Формулировка ценности

> **docflow** позволяет команде API вести документацию методов в git-репозитории так, чтобы AI находил пробелы относительно JSON-схем, человек контролировал вставки, а готовые изменения уходили в commit без смены инструмента.

## 5.5. Карта исходников (docflow)

| Роль | Путь |
