# Бизнес-требования (целевой продукт)

Документы в этой папке описывают **целевое** поведение продукта (vision / backlog): цели, пользователи, функции, сценарии и границы.

Текущее desktop-приложение в репозитории называется **docflow** (`com.eugene.docflow`). Исторически требования писались под прототип UI **DocForge** — названия в тексте BR могут ещё встречаться как синоним целевого продукта.

> **Важно:** статусы «Реализовано» в BR относились к HTML/React-прототипу DocForge и **не означают** готовность фичи в текущем Tauri-приложении.  
> Фактическое as-built состояние: **[../implemented-features.md](../implemented-features.md)**.

## Краткая формулировка ценности

**docflow** позволяет команде API вести документацию методов (AsciiDoc и связанные форматы) в git-репозитории так, чтобы AI находил пробелы относительно JSON-схем, человек контролировал вставки, а готовые изменения уходили в commit без смены инструмента.
